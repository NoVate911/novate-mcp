# novate-mcp — MCP-сервер для Notion AI

FastMCP + Docker + Caddy. Инструменты: run_command / write_file / read_file / list_files.
Notion AI подключается по адресу https://DOMAIN/mcp/
Всё, что ИИ создаст, видно в браузере на https://DOMAIN/sites/...

## Как устроена установка

Этот репозиторий — источник истины для всех файлов проекта.
install.sh — лёгкий установщик: он обновляет систему, ставит Docker и UFW,
скачивает проект из этого репозитория и запускает его.

## Первичная установка (Ubuntu 24.04)

1. Подготовь DNS: A-запись домена -> IP сервера.
2. Загрузи на сервер только install.sh (scp / SFTP), в любое место.
3. На сервере:  bash install.sh

   Скрипт сам: обновит систему, поставит Docker и git, настроит UFW,
   склонирует репозиторий в ~/mcp-server, сгенерирует токен и всё запустит.
   Если репозиторий недоступен (приватный/удалён/нет интернета) —
   покажет понятную ошибку и ничего не сломает.

4. Сохрани токен, который покажет скрипт (он также в ~/mcp-server/.env).
5. Проверка: curl -i https://ДОМЕН/mcp/  (ожидается 401 Unauthorized)

## Обновление до новой версии

1. Запушь изменения в этот репозиторий (с ПК или через веб-интерфейс GitHub).
2. На сервере:  bash ~/mcp-server/install.sh
   (скрипт сделает git pull и пересоберёт контейнеры)

.env и папка sites/ при обновлениях не трогаются.

## Настройки (.env, создаётся на сервере, в git не попадает)

| Ключ       | Что делает                                                          |
|------------|---------------------------------------------------------------------|
| MCP_TOKEN  | Секретный токен доступа (Bearer). Генерируется install.sh           |
| DOMAIN     | Домен сервера, без https:// — например novate-gpt.space             |
| SITES_DIR  | Папка на сервере, к которой у MCP есть доступ. Только она одна      |

Доступ ограничен: файловые инструменты не могут выйти за пределы SITES_DIR
(защита от ../ в коде), а контейнер видит из хостовой системы только эту
папку — она смонтирована как volume.

## Если репозиторий станет приватным

Публичный клон работает без авторизации. Для приватного нужен токен GitHub
в URL, тогда в install.sh поменяй REPO_URL на:

    https://<PERSONAL_ACCESS_TOKEN>@github.com/NoVate911/novate-mcp.git

## Подключение в Notion

- URL: https://ДОМЕН/mcp/
- Аутентификация: Bearer Token = MCP_TOKEN из .env
- Если не подключается со слэшем — попробуй без: https://ДОМЕН/mcp
- Требуется тариф Business/Enterprise и включённые Custom MCP servers
  в Settings → Notion AI → AI connectors

## Полезные команды (на сервере)

cd ~/mcp-server
docker compose ps                 # статус
docker compose logs -f mcp        # логи MCP-сервера
docker compose restart            # перезапуск
docker compose up -d --build      # пересборка после правок кода
docker compose down               # остановить всё

Смена токена: поменяй MCP_TOKEN в .env → docker compose up -d
→ обнови токен в подключении Notion.
