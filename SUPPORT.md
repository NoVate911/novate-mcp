# Поддержка

## Вопросы и помощь

Перед обращением:

1. Проверьте [README.md](README.md) и раздел диагностики.
2. Убедитесь, что используются актуальные образы `*-latest`.
3. Проверьте логи через `docker compose logs` без публикации секретов.

Для воспроизводимых ошибок используйте шаблон **Bug report**. Для идей — **Feature request**. Если GitHub Discussions включены, общие вопросы лучше задавать там.

## Что приложить

- версия или commit SHA;
- ОС, архитектура и версия Docker;
- затронутый сервис;
- минимальные шаги воспроизведения;
- очищенный от секретов фрагмент логов.

Не публикуйте токены, пароли, `.env`, `overrides.json`, содержимое бэкапов и персональные данные. Уязвимости отправляйте только по инструкции из [SECURITY.md](SECURITY.md).
